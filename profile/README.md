## Welcome to Nisshi Diskless Streaming 

Nisshi is a diskless streaming solution that is API compatible with Apache Kafka®. Because it speaks the Kafka protocol, existing clients, tools and applications work unchanged, while persisting data directly to S3, PostgreSQL, SQLite, Apache Iceberg and Delta Lake.  
 
Development is led by a team at Solace and in the open under the Apache-2.0 license, with contributions welcome. 

🧙 If you have any questions, feel free to surf our [Solace Community Forum](https://solace.community/)
